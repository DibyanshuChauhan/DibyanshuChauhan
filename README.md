## `03` - FEATURED BUILD

<div align="center">

# AI-Powered Web Search & Email Assistant

### `Live Web Information → AI Context → Actionable Workflow`

</div>

The project explores a practical question:

> **What happens when an AI application can search the web, understand the results, and turn them into an action?**

The application combines **LangChain with Tavily** to retrieve current web information instead of relying only on static model knowledge.

### The Engineering Behind It

```text
User
 │
 ▼
React Application
 │
 ▼
Redux Toolkit
 │
 ▼
REST API
 │
 ├── Authentication ── JWT + Bcrypt
 │
 ├── Validation ────── Zod
 │
 ├── AI Workflow ───── LangChain
 │
 ├── Web Search ────── Tavily
 │
 ├── Email ─────────── Nodemailer
 │
 └── Database ──────── MongoDB
```

### What makes the project interesting

* **Live web search** provides current information for time-sensitive queries.
* **LangChain** connects search results with the AI workflow.
* **Authentication** uses JWT and Bcrypt, with email verification through Nodemailer.
* **AI email generation** turns retrieved information into a usable email workflow.
* **Zod validation** keeps API input predictable.
* **Centralized error handling** prevents malformed requests from causing uncontrolled failures.
* **Redux Toolkit** manages complex asynchronous frontend state.
